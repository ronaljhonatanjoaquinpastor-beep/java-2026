# Descripción del Proyecto

Este proyecto consiste en el desarrollo de una aplicación básica como parte del curso de Desarrollo de App. El objetivo principal es aprender los fundamentos de creación de aplicaciones móviles y comprender el proceso de diseño, programación y pruebas.

---

# Objetivos

## Objetivo General

Desarrollar una aplicación funcional aplicando los conocimientos básicos del curso.

## Objetivos Específicos

* Comprender la estructura de una aplicación.
* Diseñar una interfaz sencilla y amigable.
* Implementar funcionalidades básicas.
* Realizar pruebas de funcionamiento.

---
